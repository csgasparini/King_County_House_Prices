# Final Test_Module 7_IBM Coursera

🏠 House Price Analysis - King County, WA

📊 Project Overview:
This project analyzes house sale prices in King County, Washington — including Seattle.
The dataset contains property transactions between May 2014 and May 2015, along with features like number of bedrooms, square footage, location, and more.

The goal is to explore how different features affect sale prices and to build predictive models using linear and regularized regression techniques.

----------------------------------------------------------------

📁 Dataset:
Source: Kaggle / King County Housing Data

Highlights:
Sale prices of houses
Bedrooms and bathrooms count
Living area and lot square footage
Location data (zip code, coordinates), and so on.

----------------------------------------------------------------

🔧 Tools & Technologies:
Python
Jupyter Notebook
Pandas & NumPy (data handling)
Matplotlib & Seaborn (visualization)
Scikit-learn (modeling & evaluation)

----------------------------------------------------------------

🔍 What Was Done:
Trained models with and without feature scaling
Applied polynomial transformation to capture non-linear patterns
Used Ridge regression to handle multicollinearity and prevent overfitting
Split data into training and testing sets (85% train / 15% test)

----------------------------------------------------------------

🧩 Challenges:
Identifying and treating outliers
Identify and treating missing values
Handling correlated features (multicollinearity)
Improving model performance with transformations
Understanding the math behind R² and model training

----------------------------------------------------------------

✅ Conclusion:
Features like living area size, location (latitude), view rating, and grade had the most impact on house prices.
Polynomial transformations significantly improved model performance, capturing more complex relationships beyond linear trends.
